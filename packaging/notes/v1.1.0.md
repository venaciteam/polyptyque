**Polyptyque 1.1.0 adds cropping for each source and keeps the Stream Deck plugin up to date.**

*Version française plus bas.*

## What’s new

- **Crop a source**: right-click a source, then **Crop…**. Trim each edge in pixels, freely or with a locked aspect ratio (16:9, 4:3, 3:2, 1:1, 4:5, 9:16, 21:9), with the handles, the margin fields or the keyboard. The crop applies to previews and recordings, and is saved with the source.
- **Stream Deck plugin updates**: the plugin now comes with Polyptyque. When the installed plugin is older, a pill at the top of the window (and a button in Settings, Remote control section) offers the update; Stream Deck asks for confirmation. Nothing is offered if the plugin isn’t installed.
- **Stream Deck plugin 0.1.0.3**: it introduces itself as “Stream Deck” in the “Remote control” pill.

## Fixes

- The “Remote control” pill no longer grows for a moment as if something were controlling Polyptyque: brief connections (such as the Stream Deck plugin refreshing its lists) aren’t shown anymore.
- Right-clicking a source only opens its menu; it no longer starts dragging the source.

## Downloads

- [Windows installer](https://github.com/venaciteam/polyptyque/releases/latest/download/Polyptyque-Setup.exe)
- [Portable version](https://github.com/venaciteam/polyptyque/releases/latest/download/Polyptyque-portable.zip)
- [Stream Deck plugin](https://github.com/venaciteam/polyptyque/releases/latest/download/city.vena.polyptyque.streamDeckPlugin)

Windows 10 version 2004 or later, or Windows 11, 64-bit. Stream Deck 7.1 or later is required for the plugin.

## Updating

The update is available inside Polyptyque. Scenes, sources, settings and browser sign-ins are kept. Updates are installed outside recording and conversion sessions. After updating, Polyptyque offers the new Stream Deck plugin if an older one is installed.

## Français

**Polyptyque 1.1.0 ajoute le rognage de chaque source et tient le plugin Stream Deck à jour.**

### Nouveautés

- **Rogner une source** : clic droit sur une source, puis **Rogner…**. Retirer des pixels sur chaque bord, en format libre ou verrouillé (16:9, 4:3, 3:2, 1:1, 4:5, 9:16, 21:9), avec les poignées, la saisie des marges ou le clavier. Le rognage s’applique aux aperçus et à l’enregistrement, et reste mémorisé avec la source.
- **Mise à jour du plugin Stream Deck** : le plugin est désormais livré avec Polyptyque. Si le plugin installé est plus ancien, une pastille en haut de la fenêtre (et un bouton dans les Réglages, partie Pilotage) propose la mise à jour ; Stream Deck demande la confirmation. Rien n’est proposé si le plugin n’est pas installé.
- **Plugin Stream Deck 0.1.0.3** : il se présente sous le nom « Stream Deck » dans la pastille « Pilotage ».

### Corrections

- La pastille « Pilotage » ne grandit plus un instant comme si un programme pilotait Polyptyque : les connexions éclair (le plugin Stream Deck qui relit ses listes, par exemple) n’y apparaissent plus.
- Un clic droit sur une source ouvre seulement son menu ; il ne déclenche plus le glisser de la source.

### Téléchargements

- [Installateur Windows](https://github.com/venaciteam/polyptyque/releases/latest/download/Polyptyque-Setup.exe)
- [Version portable](https://github.com/venaciteam/polyptyque/releases/latest/download/Polyptyque-portable.zip)
- [Plugin Stream Deck](https://github.com/venaciteam/polyptyque/releases/latest/download/city.vena.polyptyque.streamDeckPlugin)

Windows 10 version 2004 ou suivante, ou Windows 11, en 64 bits. Stream Deck 7.1 ou suivant est nécessaire pour le plugin.

### Mise à jour

La mise à jour est proposée dans Polyptyque. Scènes, sources, réglages et connexions des navigateurs sont conservés. Elle s’installe en dehors des enregistrements et conversions en cours. Ensuite, Polyptyque propose le nouveau plugin Stream Deck si une version plus ancienne est installée.
