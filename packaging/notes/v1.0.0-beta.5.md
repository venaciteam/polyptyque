> **Beta version.** Fifth beta of Polyptyque, not the final 1.0 yet. For an important recording, keep an eye on the files.
>
> *Version française plus bas.*

## What’s new

- **Polyptyque in English.** The whole interface, written in English from the start rather than translated word for word. Polyptyque uses French if Windows is in French, and English for any other language; Settings > “Language” switches right away, without restarting.
- **12-hour or 24-hour clock**, following the Windows regional format by default (Settings > “Clock”). Dates are written with the month’s name (“Sun, Oct 25”), and numbers with the separators of the language (“12,000 kbps”).
- **Report a problem**: Settings > “Report a problem…”, also offered after an interrupted recording. Polyptyque prepares a report (user folder and Windows account name masked), shows it in File Explorer and opens a pre-filled GitHub issue page to attach it to. Nothing is sent automatically.
- **Date of a one-time scheduled recording** chosen from three lists (day, month, year), with the day of the week shown underneath.
- Error details coming from other programs (FFmpeg, the updater…) are now written to the log instead of being shown as is: the message on screen stays in the interface language.
- Settings window: only the columns scroll; the buttons at the bottom stay visible.
- French interface: a neutral, impersonal tone.

## Fixes

- A one-time scheduled recording more than nine days away showed “Finished”, was missing from the “Schedule” button, and didn’t keep the computer awake. It now counts as upcoming, whatever its date.

## Download

- **Polyptyque-Setup.exe**: installs with no questions and no administrator rights.
- **Polyptyque-portable.zip**: no installation; unzip it anywhere, then run `Polyptyque.exe`.

Windows 10 (2004 or later) or Windows 11, 64-bit. Polyptyque isn’t signed yet: if Windows shows “Windows protected your PC”, click “More info”, then “Run anyway”.

## Updates

Copies on betas 1 to 4 get it in one click inside Polyptyque, never during a recording. Scenes, sources and sign-ins carry over as they are. The interface switches to English on a Windows that isn’t in French: Settings > “Language” to choose. This beta gets the following betas, then the stable 1.0 (Settings > Updates).

## Known limitations

- The console version (`polyptyque-console.exe`) is in French only for now.
- Scheduled recordings only start if Polyptyque is open and the computer is on: Windows doesn’t launch Polyptyque at the set time yet, or wake the computer from sleep.
- Not checked yet: starting a scheduled recording with the Windows session locked and the screen off.
- Portable version: the “Start Polyptyque when Windows starts” option is registered in Windows; turn it off before taking the folder to another PC.
- Sound is isolated per program, not per tab.
- A window minimized to the taskbar has a frozen picture (“Restore window” button on its card).
- Protected content (Netflix…) often black; games in exclusive fullscreen black.
- If a source’s browser has several windows, only the source’s window comes back at the next launch when Polyptyque closes them; the others stay under “Recently closed windows” in the browser’s history.
- Rare: if Polyptyque no longer starts after an update (for example an antivirus blocking the file replacement), reinstall it with Polyptyque-Setup.exe. Scenes, settings and sign-ins are kept.

## Reporting a problem

Settings > “Report a problem…” in Polyptyque, or the **Issues** tab of the repository.

## Version française

> **Version bêta.** Cinquième bêta de Polyptyque, ce n'est pas encore la 1.0 définitive. Pour un enregistrement important, garder un œil sur les fichiers.

### Nouveautés

- **Polyptyque en anglais.** Toute l'interface, écrite directement en anglais plutôt que traduite mot à mot. Polyptyque s'affiche en français si Windows est en français, en anglais pour toute autre langue ; Réglages > « Langue » change immédiatement, sans redémarrer.
- **Horloge sur 24 h ou 12 h**, selon le format régional de Windows par défaut (Réglages > « Horloge »). Les dates s'écrivent avec le nom du mois (« dim. 25 oct. »), les nombres avec les séparateurs de la langue (« 12 000 kb/s »).
- **Signaler un problème** : Réglages > « Signaler un problème… », aussi proposé après un enregistrement interrompu. Polyptyque prépare un rapport (dossier personnel et nom du compte Windows masqués), le montre dans l'Explorateur et ouvre une page d'issue GitHub pré-remplie où le joindre. Rien n'est envoyé automatiquement.
- **Date d'une programmation « une seule fois »** choisie dans trois listes (jour, mois, année), avec le jour de la semaine rappelé dessous.
- Les détails d'erreur venus d'autres logiciels (FFmpeg, l'outil de mise à jour…) sont écrits au journal au lieu d'être affichés tels quels : le message à l'écran reste dans la langue de l'interface.
- Fenêtre des réglages : seules les colonnes défilent, les boutons du bas restent visibles.
- Interface française au ton neutre et impersonnel.

### Corrections

- Une programmation « une seule fois » à plus de neuf jours s'affichait « Terminée », manquait à la pastille « Programmer » et n'empêchait pas la mise en veille. Elle compte désormais comme à venir, quelle que soit sa date.

### Télécharger

- **Polyptyque-Setup.exe** : installation sans question ni droits administrateur.
- **Polyptyque-portable.zip** : sans installation ; décompresser où l'on veut, puis lancer `Polyptyque.exe`.

Windows 10 (2004 ou plus récent) ou Windows 11, 64 bits. Polyptyque n'est pas encore signé : si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires », puis « Exécuter quand même ».

### Mises à jour

Les copies en bêta 1 à 4 la reçoivent d'un clic dans Polyptyque, jamais pendant un enregistrement. Scènes, sources et connexions sont reprises telles quelles. Sur un Windows qui n'est pas en français, l'interface passe en anglais : Réglages > « Langue » pour choisir. Cette bêta reçoit les bêtas suivantes, puis la 1.0 stable (Réglages > Mises à jour).

### Limites connues

- La version console (`polyptyque-console.exe`) reste en français pour l'instant.
- Les enregistrements programmés ne démarrent que si Polyptyque est ouvert et l'ordinateur allumé : Windows ne lance pas encore Polyptyque à l'heure prévue, ni ne sort l'ordinateur de veille.
- Pas encore vérifié : le démarrage d'un enregistrement programmé avec la session Windows verrouillée et l'écran éteint.
- Version portable : l'option « Lancer Polyptyque au démarrage de Windows » est inscrite dans Windows ; la couper avant d'emporter le dossier sur un autre PC.
- Le son est isolé par programme, pas par onglet.
- Une fenêtre réduite dans la barre des tâches a une image figée (bouton « Rétablir la fenêtre » sur sa carte).
- Contenus protégés (Netflix…) souvent en noir ; jeux en plein écran exclusif en noir.
- Si le navigateur d'une source a plusieurs fenêtres, seule celle de la source revient au lancement suivant quand Polyptyque les ferme ; les autres restent dans « Fenêtres récemment fermées » de l'historique du navigateur.
- Rare : si Polyptyque ne démarre plus après une mise à jour (par exemple un antivirus qui bloque le remplacement des fichiers), le réinstaller avec Polyptyque-Setup.exe. Scènes, réglages et connexions sont conservés.

### Signaler un problème

Réglages > « Signaler un problème… » dans Polyptyque, ou onglet **Issues** du dépôt.
